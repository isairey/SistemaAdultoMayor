## 📌 Formas de contribuir

Puedes colaborar de distintas maneras:

- 🐛 Reportando errores (bugs)  
- 💡 Proponiendo mejoras  
- 📖 Mejorando la documentación  
- 💻 Enviando código (Pull Requests)  

---

## 🐛 Reportar errores

Si encuentras un problema, crea un **Issue** incluyendo:

- 🏷️ Título claro y descriptivo  
- 🔁 Pasos para reproducir el error  
- 📷 Evidencia (capturas o logs)  
- 🎯 Resultado esperado vs resultado actual  

📌 Antes de crear un Issue:
- Verifica que no exista uno similar  
- Revisa si ya fue solucionado  

---

## 💡 Sugerencias de mejora

Las mejoras también se gestionan mediante Issues.

Incluye:

- 📌 Descripción clara  
- ⚙️ Comportamiento actual  
- 🚀 Beneficio esperado  

💡 Consejo:  
Las mejores propuestas son específicas y viables.
